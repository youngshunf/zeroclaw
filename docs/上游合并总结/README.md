# 上游合并总结

本目录保存每次从 `upstream`（`zeroclaw-labs/zeroclaw`）合并到唤星 `huanxing` 分支后写的**新功能总结**。

## 约定

- **一次合并一份文档**，文件名 `YYYY-MM-DD.md`（合并完成当日日期）。
- **必须用中文书写**。
- 合并 commit 完成后立即写，不延期。

## 文档应覆盖的内容

| 小节 | 必填 |
|---|---|
| 基本信息（版本跳转、commit 数、冲突数、merge commit SHA） | ✅ |
| 按分类列出的上游新功能（Agent/Provider/渠道/插件/Config/Memory/可观测性/Skills/CI/发布/文档） | ✅ |
| 每项附 **PR 号 + 改动 + 对唤星影响**（🟢 受益 / 🟡 需验证 / 🔴 高风险） | ✅ |
| 对唤星 fork 的影响评估（冲突面 / 签名兼容 / HASN / 桌面端 / 编译 / clippy） | ✅ |
| 待跟进事项（冒烟测试、后续清理、值得评估采用的上游新机制） | ✅ |
| 合并命令回放 | ✅ |

## 与 `docs/merge-notes/` 的区别

- `docs/merge-notes/` — 合并**过程中**的工作交接（handoff），面向中断后接手的开发者。
- `docs/上游合并总结/`（本目录） — 合并**完成后**的新功能清单，面向事后查询"上游 0.7.3 给了我们什么"。
